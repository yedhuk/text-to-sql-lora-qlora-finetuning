# (the code in this repo is written against these exact versions). torch and
# bitsandbytes are handled specially because Blackwell needs recent CUDA kernels.

# INSTALL ORDER (use a fresh venv):
#   python -m venv .venv && source .venv/bin/activate
#   pip install torch --index-url https://download.pytorch.org/whl/cu128
#   pip install -r requirements.txt
#
# torch is intentionally NOT listed here — install it from the cu128 index FIRST
# (line above). A plain `pip install torch` pulls a build without sm_120 kernels
# and your 5080 silently won't accelerate (or errors out).
